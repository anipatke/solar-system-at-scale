# solar-system-at-scale — v1 Release Plan

## Release goal

Turn the existing scale journey into a quiet, polished solar-system experience with lightweight 3D bodies, restrained supporting UI, and documentation that accurately describes this repository.

## Epic list

| # | Epic | Status |
|---|------|--------|
| E01 | Project documentation reset | audited |
| E02 | Lightweight 3D planet system | planned |
| E03 | Sparse 3D asteroid belt | planned |
| E04 | Interface, motion, and audio cleanup | planned |

## Out of scope for this release

- Photorealistic simulation or physically exact lighting.
- Large downloaded 3D models, a framework migration, or a build pipeline.
- Literal moon-system distance scaling on the main AU axis.
- Additional planets, probes, moons, narrated content, or ambient audio.
- Redesigning the core horizontal scale journey or Pluto endpoint.
