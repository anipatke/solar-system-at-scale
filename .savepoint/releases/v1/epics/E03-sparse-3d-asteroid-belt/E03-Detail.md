# E03: Sparse 3D Asteroid Belt

## Purpose

Replace the current brown haze and random dots with a sparse, dimensional asteroid-belt passage.

## Planned value

- Use a small reusable set of irregular 3D rocks with varied scale, rotation, and depth.
- Remove the fog-like rectangular band and preserve large gaps between visible objects.
- Use restrained parallax and gradual entry/exit across the existing 2.2–3.2 AU region.
- Include only a few named major bodies when they improve orientation.

## Dependencies

- E02 supplies the shared 3D rendering foundation.

## Boundaries

No dense cinematic debris field, collision simulation, or scientifically literal population count.

## Open decisions

None. Mobile is capped at 80 instances; Ceres gets one orientation label without focus or card behavior.
